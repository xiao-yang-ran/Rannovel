# RanNovel

RanNovel 是完全离线的 Windows 桌面写作应用，使用 PySide6、SQLite 和 SQLAlchemy。它没有云服务、在线素材或遥测。

## 启动

使用 Python 3.10+ 安装 `requirements.txt`，运行 `python main.py`；无控制台入口为 `RanNovel.pyw`。桌面快捷方式可由 `create_rannovel_shortcut.ps1` 创建。所有入口都进入唯一的 `app` 包。

## 作品与正文

顶部“作品”菜单可新建长篇、随笔、片段，打开常用或归档作品，归档后仍可编辑并恢复到常用列表。长篇包含独立的分卷、分章、地点、世界设定和时间线。随笔及片段各有一篇独立正文。人物库和关系图全局共享。

正文支持富文本排版、自动保存、字数统计、查找替换，以及从文件管理器拖入或通过按钮插入图片。人物、地点、事件、设定和灵感按正文类型限制关联。灵感库包含随笔池、长篇池和统一已使用列表；片段使用长篇池。待用灵感可拖到作品，也可用按钮归属。人物、地点、灵感的图库支持多图。

## 数据与备份

正式数据在 `%APPDATA%\RanNovel\`：`rannovel.db` 是数据库，`assets\` 是受管理图片，`backups\` 是默认备份目录。程序目录里的旧数据库及已核实没有创作内容的旧版备份已从最终项目中移除；不会清理 AppData 中的正式资料。若以后检测到程序目录存在含创作内容的旧库，启动会停止并提示人工处理。新库用 SQLite `user_version` 管理结构版本，并为升级保留安全快照。

“文件 → 立即备份”生成包含数据库与全部管理图片的 ZIP。“从 ZIP 恢复”先检查格式、哈希、SQLite 完整性和关联，再创建安全备份；原图片目录也会保存在备份目录中。恢复失败会尝试回退。新版恢复接受版本 2 的整库 ZIP；旧版 ZIP 不会被改写，若要取回旧版内容，请在旧版程序中处理。

## 发布

运行 `python build_release.py` 创建 `RanNovel_1.0_final.zip`。发布包只包含运行所需源码，不包含任何用户资料、旧版实现或测试文件。界面将大纲、资料和灵感的次要操作收纳进菜单，同时保留常用按钮。交付前通过源码语法检查与独立临时数据库的界面、作品切换和正文保存验证；项目不包含测试脚本。
