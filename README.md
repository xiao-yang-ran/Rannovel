# RanNovel 1.1.0

RanNovel 是完全离线的 Windows 桌面写作应用，使用 PySide6、SQLite 和 SQLAlchemy。它没有云服务、在线素材或遥测。

## 安装与启动

推荐使用 Python 3.12。安装本版本已验证的依赖后启动：

```powershell
python -m pip install -r requirements.txt
python main.py
```

无控制台入口为 `RanNovel.pyw`，所有入口均进入 `app` 包。快捷方式脚本保留原有默认环境路径；如需指定本机环境，可运行 `create_rannovel_shortcut.ps1 -EnvironmentPath "你的环境目录"`。同一资料目录只允许一个 RanNovel 实例运行，避免多个窗口互相覆盖正文。

## 创作与资料

- “作品”菜单可新建长篇、随笔、片段，打开或归档作品；归档作品仍可编辑并恢复到常用列表。作品选择支持搜索，并用编号区分同名作品。
- 长篇拥有独立的分卷、分章、地点、设定和时间线。随笔与片段各有一篇正文，人物库和人物关系全局共享。时间线按年月排列。
- 正文支持富文本、800 毫秒防抖自动保存、字数统计和查找替换。切换章节、作品、页面以及备份或退出前都会尝试保存；保存失败时保留当前正文。
- 可通过按钮、文件拖放或剪贴板图片插入正文图片。粘贴包含外部图片的 HTML 时保留纯文字，并提示单独导入图片，避免正文陷入无法保存的状态。
- 关联资料和事件人物可搜索、分页加载。灵感分为随笔池与长篇池，片段使用长篇池；可归属作品并关联具体正文。“解除正文关联”保留作品归属，“文件 → 已使用灵感…”中的“放回待用池”则同时解除二者。
- 人物、地点、灵感可添加多张图片。同一图片重复导入会复用资源。单张图片上限为 50 MiB、4000 万像素。管理已有配图会立即保存；文本编辑表单的取消不撤销已经执行的配图管理。
- 关系图支持搜索，每次显示最多 200 人，超出时提示缩小搜索范围。表单校验失败时保持打开；普通资料字段以纯文字保存。

## 正式数据与图片清理

正式数据位于 `%APPDATA%\RanNovel\`：`rannovel.db` 为数据库，`assets\` 为受管理图片，`backups\` 为默认备份目录。

图库移除图片后，程序会检查所有图库和正文引用再回收资源。当前编辑器撤销记录可能用到的图片会暂时保留；切换作品或正常退出后会再次清理。备份只包含已保存正文和图库仍使用的图片。已有 ZIP 备份中的内容不会被自动改写或删除。

启动时始终检查程序目录中的 `data\rannovel.db`。如果旧库含有数据，会停止并要求人工核实，无论 AppData 中是否已有正式库。程序不会自动删除或合并旧库。SQLite `user_version` 管理结构版本，版本 1 升级到版本 2 前保留数据库安全快照；迁移失败时回滚结构变更。

## 备份与恢复

“文件 → 立即备份”在后台创建 ZIP，检查数据库结构、SQLite 完整性、跨表关联、正文图片引用，以及实际写入 ZIP 的图片哈希。正在使用的资源丢失或内容被外部改动时会报错，不会留下标记为成功的 ZIP。

“从 ZIP 恢复”接受格式版本 2、数据库版本 2 的整库备份。解压前检查重复成员、文件路径与大小限制，再验证哈希和业务关联；通过后才替换当前资料。单个成员上限为 4 GiB，整包解压上限为 20 GiB，成员数量上限为 100002。

恢复前保留安全备份，失败时回退数据库和图片。如果当前资料因图片缺失或完整性问题无法正常备份，会改存 `recovery_before_restore_*.zip` 原始资料包后继续恢复。原始资料包供人工取回内容，不可直接通过“从 ZIP 恢复”导入。成功恢复后不再额外保留一份重复的旧图片目录；安全 ZIP 会一直保留。请按自身需要定期管理备份目录。

旧格式 ZIP 不会被改写；需要取回旧版内容时，应使用对应旧版程序处理。

## 源码与发布

`app/domain.py` 定义公共规则；`app/services/` 包含资料库、完整性校验和备份恢复；`app/ui/` 按正文、资料、灵感、图片、关系图及通用对话框分模块。

运行 `python build_release.py` 生成 `RanNovel_1.1.0_final.zip`。发布包仅包含运行源码、说明、依赖清单、图标和快捷方式脚本，并附带每个文件的 SHA-256 清单。相同源码重复构建会生成相同内容的 ZIP。用户数据、历史文件、缓存和测试脚本不进入发布包。

本次临时验证覆盖数据迁移、故障回退、损坏备份、图片引用与撤销、表单和页面切换等场景；验证完成后按交付要求移除测试文件。验证范围和版本变更见 `RELEASE_NOTES.md`。
